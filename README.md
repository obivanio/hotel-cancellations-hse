# Отмены бронирований в отелях: прогноз и политика предоплаты

Итоговый проект программы ДПО НИУ ВШЭ «Аналитика данных».

**Вопрос:** какие брони отменят и сколько отель сэкономит, если брать предоплату только с
рискованных броней?

## Данные

Hotel Booking Demand — 119 390 броней двух отелей в Португалии (городской и курортный),
заезды с июля 2015 по август 2017, 32 признака.
Источник: Antonio, Almeida, Nunes. *Hotel booking demand datasets*. Data in Brief, 2019.

Датасет скачивается автоматически при первом запуске (`src/data.py`) в `data/raw/`.

## Структура

```
src/          код: загрузка (data), очистка (cleaning, cleaning_log), признаки (features), сборка (pipeline),
              разведочный анализ (eda), статистика (stats), гипотезы (hypotheses), графики (plots),
              модель: сплит (split), признаки модели (model_features), правила (baselines), модели (models),
              оценка и порог (evaluation); экономика: правила предоплаты (policies), овербукинг (overbooking),
              интерактивный отчёт (report), расчёты дашборда (dashboard)
app.py        дашборд Streamlit для бизнеса
tests/        тесты pytest
notebooks/    ноутбуки с ходом работы и выводами (01 — загрузка и очистка, 02 — анализ и гипотезы, 03 — модель,
              04 — экономика предоплаты и овербукинга)
data/raw/     исходные данные (скачиваются автоматически, не хранятся в git)
data/processed/  очищенный датасет (создаётся ноутбуком, не хранится в git)
models/       обученная модель CatBoost
reports/      артефакты: журнал очистки, таблица гипотез, метрики моделей, таблицы правил и овербукинга,
              интерактивный отчёт report.html (открывается в браузере без Python), вероятности броней для
              дашборда (scored_test.csv, scored_valid.csv), графики и схемы (figures/)
```

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .
jupyter notebook notebooks/
```

## Дашборд

Интерактивный дашборд для бизнеса: слева фильтры (отель, сегмент продаж, месяц заезда) и ползунки допущений о
деньгах, сверху «стена из 100 плиток» и ключевые цифры, ниже вкладки — правила предоплаты, овербукинг, риск по
сегментам, интерактивные схемы модели, допущения. Всё пересчитывается сразу при смене фильтров.

Стена — 100 типичных броней выбранного среза: плитка в синей рамке — модель берёт предоплату, плитка цвета охры —
бронь отменят. Цвет везде значит одно и то же: синий — модель и городской отель, бирюзовый — курортный отель, охра —
отмены и потери, серый — бенчмарки и простые правила. Шрифт Golos Text (лицензия OFL) лежит в `static/fonts/`.

Модель и исходные данные дашборду не нужны: он читает готовые таблицы из `reports/`, поэтому работает без
интернета и без обучения.

На чистом компьютере (нужен Python 3.11 или новее; проверено на 3.14):

```bash
git clone https://github.com/obivanio/hotel-booking-cancellations.git && cd hotel-booking-cancellations
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Браузер сам не откроется: после запуска откройте адрес http://localhost:8501. Посмотреть результаты без Python
можно в `reports/report.html`.
